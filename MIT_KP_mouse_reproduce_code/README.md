
# MIT/KPTracer Mouse Data Reproducibility

This README describes the LINEMAP workflow used for the MIT/KPTracer mouse
lineage tracing analysis.

## Data Source

The KPTracer/MIT mouse data were downloaded from Zenodo:

```text
Processed data for KP-Tracer Tumors from study
"Lineage Recording Reveals the Phylodynamics, Plasticity and Paths of Tumor Evolution"

```
https://doi.org/10.5281/zenodo.5847461

The DOI redirects to the Zenodo processed data release containing:

```text
KPTracer-Data.tar.gz
```

Because these data were not generated by us, the raw downloaded files are not
redistributed here. Users who want to rerun preprocessing from the original
files should download `KPTracer-Data.tar.gz` from Zenodo.

## Required Raw Files for Rebuilding

After extracting `KPTracer-Data.tar.gz`, the rebuilding pipeline expects:

```text
KPTracer_meta.csv
KPTracer.alleleTable.unfiltered.txt
plasticity_scores.tsv
KP_mice_metadata.xlsx
fitnesses/*.tsv
expression/adata_processed.nt.h5ad
```

Set `KPTRACER_DATA_DIR` to the extracted `KPTracer-Data` directory before
running scripts that rebuild from raw data.

## Code

The analysis scripts are provided in the `updated_linemap_pipeline` folder.
After downloading this repository, run the commands below from the repository
root directory.

```text
MIT_KP_mouse_reproduce_code/
```

Main scripts:

```text
01_build_transition_inputs.R
02_build_one_mouse_save_list.R
03_combine_mouse_save_lists.R
04_plot_from_save_list.R
05_cross_mouse_summary_figures.R
mit_linemap_helpers.R
mouse_configs_static.R
```

These scripts use the public `LINEMAP` package for transition matrix
estimation, distance dictionary construction, probabilistic distance
calculation, and tree reconstruction.

Mouse-specific tumor groups, colors, intBC counts, and clonal thresholds are
predefined in `mouse_configs_static.R`, so users do not need an extra
configuration step.

## Step 0: Use the reproduce code
```bash
git clone https://github.com/methodistsmab/LINEMAP-data-preprocessing.git
cd LINEMAP-data-preprocessing/MIT_KP_mouse_reproduce_code
```

## Step 1: Build Transition Inputs

This step estimates the three sgRNA transition matrices and builds the LINEMAP
distance dictionaries used for cell-cell distance calculation.

```bash
KPTRACER_DATA_DIR=/path/to/KPTracer-Data \
Rscript 01_build_transition_inputs.R
```

Output directory:

```text
outputs/
```

Output file:

```text
outputs/linemap_transition_inputs_fixed_all.rds
```

The output object stores:

```r
P
dictionary
```

`P` is a list of three transition matrices, one for each sgRNA readout group
(`r1`, `r2`, and `r3`). Each matrix summarizes the estimated transition
probabilities among observed barcode states.

`dictionary` is a list of precomputed pairwise distance lookup tables for the
same three readout groups. These tables are reused across intBC positions when
constructing the probabilistic cell-cell distance matrix.

## Step 2: One Mouse Runnable Example

This example demonstrates how a single mouse is rebuilt from the Zenodo data and
stored transition inputs. It saves the selected sample, sequence matrix, distance
matrix, cell table, and one-mouse `save_list`.

Example for mouse `3522`:

```bash
KPTRACER_DATA_DIR=/path/to/KPTracer-Data \
MOUSE_ID=3522 \
Rscript 02_build_one_mouse_save_list.R
```

Output directory:

```text
outputs/mouse_3522/
```

Output files:

```text
outputs/mouse_3522/save_list_3522.rds
outputs/mouse_3522/sample_3522.rds
outputs/mouse_3522/sequence_3522.rds
outputs/mouse_3522/distance_with_C0_3522.rds
outputs/mouse_3522/cell_table_3522.csv
```

The one-mouse list contains:

```r
save_list[[mouse_id]]$meta
save_list[[mouse_id]]$sample
save_list[[mouse_id]]$sequence
save_list[[mouse_id]]$cellBC
save_list[[mouse_id]]$distance_probability_matrix
save_list[[mouse_id]]$distance_to_root
save_list[[mouse_id]]$dist_object
save_list[[mouse_id]]$hclust1
save_list[[mouse_id]]$dend1
save_list[[mouse_id]]$asdist_matrix
save_list[[mouse_id]]$hclust2
save_list[[mouse_id]]$dend2
save_list[[mouse_id]]$D
save_list[[mouse_id]]$tree_nj
save_list[[mouse_id]]$table
save_list[[mouse_id]]$colors
```

To generate the three mouse-level tree plots for this example:

```bash
SAVE_LIST_FILE=outputs/mouse_3522/save_list_3522.rds \
MOUSE_ID=3522 \
Rscript 04_plot_from_save_list.R
```

This creates the one-mouse tree figures:

```text
outputs/figures/3522/3522_dist_distance_matrix_clone_seperation.pdf
outputs/figures/3522/3522_reconstructed_tree_UPGMA.pdf
outputs/figures/3522/3522_reconstructed_tree_NJ.pdf
```

## Optional: Rebuild Additional Mice One at a Time

Users who want to inspect or regenerate additional mouse-level objects can run
the same script with a different single mouse ID:

```bash
KPTRACER_DATA_DIR=/path/to/KPTracer-Data \
MOUSE_ID=3430 \
Rscript 02_build_one_mouse_save_list.R

KPTRACER_DATA_DIR=/path/to/KPTracer-Data \
MOUSE_ID=3433 \
Rscript 02_build_one_mouse_save_list.R

KPTRACER_DATA_DIR=/path/to/KPTracer-Data \
MOUSE_ID=3507 \
Rscript 02_build_one_mouse_save_list.R
```

The script intentionally rebuilds one mouse at a time. This keeps resource use
explicit and avoids launching a long full-cohort reconstruction by accident.
For large mice, users should expect substantially longer runtimes and higher
memory use.

Output directory for each mouse:

```text
outputs/mouse_<MOUSE_ID>/
```

## Step 4: Generate One-Mouse Tree Figures From an All-Mouse save_list

The tree-plot script can read either an all-mouse `save_list` or the one-mouse
`save_list` generated in Step 2.

All-mouse inputs:

```text
/path/to/save_list_all_mice_linemap.rds
/path/to/save.list.04072026.RDS
```

One-mouse input from Step 2:

```text
outputs/mouse_3522/save_list_3522.rds
```

Generate the three tree plots for one mouse:

```bash
SAVE_LIST_FILE=/path/to/save.list.04072026.RDS \
MOUSE_ID=3522 \
Rscript 04_plot_from_save_list.R
```

This step does not require the raw KPTracer files.

Output directory:

```text
outputs/figures/3522/
```

Output files:

```text
outputs/figures/3522/3522_dist_distance_matrix_clone_seperation.pdf
outputs/figures/3522/3522_reconstructed_tree_UPGMA.pdf
outputs/figures/3522/3522_reconstructed_tree_NJ.pdf
```

To generate tree plots for every mouse stored in an all-mouse `save_list`, use:

```bash
SAVE_LIST_FILE=/path/to/save.list.04072026.RDS \
MOUSE_ID=ALL \
Rscript 04_plot_from_save_list.R
```

Batch output directory:

```text
outputs/figures/<MOUSE_ID>/
```

Very large mice may require more memory or C stack space during tree plotting.
If one mouse fails during `MOUSE_ID=ALL`, the script reports that mouse and
continues plotting the remaining mice. Large mice can also be plotted
individually by setting `MOUSE_ID` to one mouse ID.

## Step 5: Generate Cross-Mouse Figures From an All-Mouse save_list

Use either the combined object from Step 3 or the provided all-mouse object:

```text
/path/to/save_list_all_mice_linemap.rds
/path/to/save.list.04072026.RDS
```

Generate cross-mouse figures:

```bash
SAVE_LIST_FILE=/path/to/save.list.04072026.RDS \
KPTRACER_DATA_DIR=/path/to/KPTracer-Data \
Rscript 05_cross_mouse_summary_figures.R
```

This script uses the all-mouse `save_list` plus the supporting annotation files
in `KPTRACER_DATA_DIR`:

```text
Expression_data_index.xlsx
trcr_master.txt
expression/adata_processed.nt.h5ad
```

`Expression_data_index.xlsx` provides cell IDs and UMAP coordinates.
`trcr_master.txt` provides `MouseID`, `Aging_Month`, and `Genotype` for the
age/genotype plots.
`expression/adata_processed.nt.h5ad` provides the expression matrix for the
gene-height correlation example using Mesenchymal-1/Mesenchymal-1 (Met) sgNT
cells.

Only `celltype_height_boxplot.pdf` can be generated from the all-mouse
`save_list` alone; the other figures require `KPTRACER_DATA_DIR`.

Output directory:

```text
outputs/cross_mouse_figures/
```

Output files:

```text
outputs/cross_mouse_figures/celltype_height_boxplot.pdf
# UPGMA height by cell state

outputs/cross_mouse_figures/UMAP_height2_all_cells.pdf
# UMAP colored by UPGMA height

outputs/cross_mouse_figures/Mesenchymal_zoom_UMAP.pdf
# Mesenchymal cell-state UMAP zoom

outputs/cross_mouse_figures/Early_EMT1_zoom_UMAP.pdf
# Early EMT-1 UMAP zoom

outputs/cross_mouse_figures/EMT_distribution_bymonth.pdf
# Early EMT-1 height density by age

outputs/cross_mouse_figures/Mesenchymal_distribution_bymonth.pdf
# Early EMT-1 height histogram by age

outputs/cross_mouse_figures/gene_height_correlation_examples.pdf
# Mesenchymal gene expression correlated with UPGMA height
```

## Notes

- `NC` denotes the unedited/root barcode state, not missing data.
- Technical missing values are mapped to `"MISSING"` in LINEMAP distance
  dictionaries.
- KPTracer allele labels containing `[None]` are treated as observed allele
  labels, not technical missing values.
- The updated workflow stores `sample` and `sequence` in each mouse-level
  `save_list`, so downstream figures can be generated without reloading raw
  allele tables.
